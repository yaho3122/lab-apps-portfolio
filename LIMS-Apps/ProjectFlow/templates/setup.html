Label Logic Guide

📌 Fixed Rows:

Generates a set number of labels (defined in 'Value') for every sub-project line.

🧬 Formula (v2 based):

Calculates labels based on transformation counts. Formula: ceil((v2 / 6) * 1.1).

🌿 RS Entry Based:

Generates 1 label per plant recorded in RS description. Inherits 'Pre' structure if description is empty.

🧪 Germplasm B0:

Special multi-block logic (B0/B1/B2) with a multiplier set in the 'Value' field.
